# 专业工具原型准备

本目录用于把现有 Vue 页面转为专业设计工具中的可点击原型。当前状态为素材准备，尚未创建 Figma、墨刀或 Axure 项目，也没有专业工具分享链接；截图和流程说明不能单独作为原型工具交付成果。

运行 `node scripts/prepare_prototype.js`，在隔离 SQLite 数据库中生成虚拟展示数据，用独立浏览器截图。该脚本不读取、复制或改动本机使用库及公网演示库。生成文件在 `references/<时间>/`，包括页面图片及可见控件坐标清单 `screens.json`；数据库和测试浏览器留在 `.cache/`。

## 页面和交互范围

| 页面 | 原型中应设置的交互 |
| --- | --- |
| 首页 | 闲置、论坛入口；搜索浮层、搜索结果、无结果与关闭 |
| 闲置列表 | 搜索、分类、排序、商品卡片、底部导航 |
| 商品详情 | 返回、收藏状态、联系弹窗、预订弹窗、预订成功、分享反馈 |
| 发布商品 | 图片选择、标题描述价格分类地点、校验、提交中、成功后新增商品 |
| 论坛列表 | 分类、搜索、帖子详情、发帖、个人帖子列表 |
| 帖子详情 | 返回、评论输入及成功状态、点赞开关；点赞需在工具中补设计 |
| 个人中心 | 我的发布、收藏、交易、帖子，以及任务书中的参与讨论列表 |
| 补充页面 | 登录、注册、发帖表单、联系方式与预订弹窗 |

制作时采用现有品牌绿、论坛蓝、字号、图片和圆角作为依据。页面图用于参考，工具内还需建立可编辑页面、按钮热点、跳转、覆盖弹窗和状态切换。预设数据仅表示设计演示，不要求原型写入真实后端。

## 核心流程

1. 首页 → 闲置列表 → 分类或搜索 → 商品详情 → 收藏切换 → 预订弹窗 → 成功状态。
2. 闲置列表 → 发布 → 必填校验 → 填写 → 提交中 → 发布成功 → 列表新增商品。
3. 首页 → 论坛列表 → 帖子详情 → 点赞或评论 → 成功状态。
4. 论坛列表 → 发帖 → 提交 → 新帖列表与详情。
5. 个人中心 → 我的发布、收藏、交易、帖子或参与讨论 → 对应列表 → 返回。
6. 未登录状态 → 发布或个人中心 → 登录 → 返回原操作页面。

## 最终交付门槛

- 在课程认可的专业原型工具内覆盖至少七个核心页面，并保存工具名称及项目。
- 检查每条交互在工具预览中可操作，而不是只有图片。
- 补齐点赞、参与讨论等原型要求；未在当前 Vue 中实现的部分单独标记，不混淆实现进度。
- 创建工具原型分享链接，并验证接收方权限及实际可访问性。
- 与 Vue 网页演示地址分别列出，不能将临时隧道或截图文件称为专业工具分享链接。

候选工具为 Figma（支持交互原型和分享），任务书同时列举 Axure、墨刀等。当前 Figma 尚未连接，下一步需要用户完成安装/账号授权，随后继续创建和验证工具项目；具体课程认可范围以老师要求为准。
