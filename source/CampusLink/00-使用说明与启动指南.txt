========================================================
     福帮帮 (CampusLink) 前端交互原型系统 · 使用说明
========================================================
基准机型：iPhone 18 Pro Max
标准逻辑尺寸：440 CSS px × 956 CSS px (宽高比 440:956)
技术栈：Vue 3 + TypeScript + Vite 6
最新更新状态：
1. 品牌 Logo 细节修复：修复第二个“帮”字右上角笔画末梢与嫩绿飞溅光芒完整展示，无任何截断；
2. 登录与注册认证页面深度视觉优化：统一品牌风格体系、去 AI 模板化（彻底移除模拟状态栏、消除发光球与厚重卡片、复用绿黑书法Logo与水彩校园插画）；
3. 标准移动端视口尺寸约束、长列表独立纵向滚动与全局吸底导航栏隔离。

--------------------------------------------------------
一、如何一键启动（三种方式）
--------------------------------------------------------
【方式一：推荐老师/助教/同学评审演示（完全免装环境）】
  -> 直接双击运行：【双击直接预览(免装环境).bat】
  -> 特点：
     1. 电脑上完全不需要安装 Node.js / npm，任何 Windows 电脑双击即开！
     2. 内置基于 Windows PowerShell 的轻量 HTTP 服务，自动寻找端口并在默认浏览器中弹出。
     3. 完整支持 SPA 前端路由与全部页面交互。

【方式二：前端开发人员二次开发（源码热更新）】
  -> 直接双击运行：【一键启动(源码开发版).bat】
  -> 特点：
     1. 自动检测系统 Node.js 环境；
     2. 首次运行自动检测 node_modules，缺失时自动通过国内镜像源极速安装；
     3. 启动 Vite 开发热更新服务器（HMR）并自动打开浏览器。

【方式三：本地生产包预览】
  -> 直接双击运行：【一键启动预览.bat】
  -> 本地预览经过极致压缩编译后的生产环境代码。

二、核心页面体验指引与路由
--------------------------------------------------------
1. 首页 (/)
   - 包含福大活力绿品牌区、校园微风景插画、胶囊搜索浮层、二手闲置/校园论坛双入口、最新闲置横向滚动流、论坛攻略精选。
2. 二手闲置页 (/idle)
   - 5 类标签横向滑动筛选、最新/价格排序、自适应双列商品流。
   - 右下角悬浮绿色「+ 发布」按钮：点击直达发布闲置页！
3. 发布闲置页 (/publish)
   - 支持多图上传（实拍/多选上传/首张封面）、标题/描述实时字数统计、价格小数校验、8 大分类单选、旗山/铜盘/怡山校区切换、接受小刀议价开关。
   - 发布后自动写入前端本地 Mock 列表首位，返回闲置列表即可查看。
4. 商品详情页 (/product/1)
   - 大图展示、福大学子认证标、面交地点指引、收藏切换、聊一聊与预订。
   - 顶栏吸顶、正文内容独立滚动、底部「立即购买」操作栏固定在 App 内。
5. 校园论坛页 (/forum)
   - 6 大攻略板块切换、帖子双栏排版、发帖入口。
6. 帖子详情页 (/forum/1)
   - 经验分享正文、点赞/关注/评论互动。
7. 个人中心 (/profile)
   - 个人资料、交易与互动统计、发布宝贝入口、底部「退出登录/切换账号」入口。
8. 登录页 (/login) 与 注册页 (/register)
   - 深度去 AI 模板化：复用福帮帮绿色与黑色动感书法 Logo（完整呈现飞溅绿芒）、右上角福州大学校园风景水彩插画极淡融合；
   - 彻底移除人为绘制的 9:41 状态栏与发光光斑，融入式舒朗布局；
   - 手机号/学号登录、密码明暗文切换、协议勾选、注册自动重定向并回填账号。

--------------------------------------------------------
三、标准尺寸约束与页面滚动特性说明
--------------------------------------------------------
1. App 显示区域严格固定为 440 × 956 CSS px，与 iPhone 18 Pro Max 物理屏幕逻辑尺寸 1:1 对齐；
2. 页面内容增多时长列表在 App 内部独立纵向滚动，外部显示区域保持静止，不推动整个 App；
3. 底部导航栏宽度完全限制在 App 440px 范围内，滚动到底部时内容天然不被导航栏遮挡；
4. 浏览器窗口空间不足时（如 PC 浏览器高度小于 956px），系统自动按 440:956 纵横比等比例缩小整体预览区域，内部逻辑坐标系和 UI 比例绝对不受挤压影响。
