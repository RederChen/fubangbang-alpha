## 包内内容与完成范围

交接包包含配套的 Vue 前端、`backend/` FastAPI 后端、编译后的网页、启动脚本、接口说明和验收记录。前后端提交号及网页资源校验值见 `.releases/<版本>/manifest.json`，压缩包旁的 `.sha256` 文件用于完整性校验。

- 账号：注册、登录、登录状态恢复、个人资料和联系方式。
- 商品：封面上传、草稿、发布、浏览、分类搜索、编辑、删除及状态管理。
- 交易：收藏、查看卖家联系方式、申请预订、卖家接受或拒绝、取消、确认面交完成。
- 论坛：发帖、可选封面、分类搜索、分页、评论，以及本人帖子和评论管理。
- 运行交付：PostgreSQL 数据保存、旧库新增表、备份恢复、本机部署和临时公网演示。

组员原有成果包括页面设计、九个前端页面及基础交易后端。接手后完成真实前后端联调、缺失管理页面、图片上传、交易冲突修复、真实论坛、数据库运行环境、测试和交付整理；贡献应按各自 Git 提交区分。

## 新机器首次运行

已验证环境为 Windows 64 位、Node.js 24、Python 3.12。解压到独立文件夹后，在项目根目录执行：

```powershell
npm ci
npm run setup:backend
npm run setup:postgres
npm run start:release
```

安装依赖和首次下载项目内 PostgreSQL 需要联网。包内已包含编译页面，首次体验无需重新构建。打开 `http://127.0.0.1:8080/`；后续可双击 `run-production.bat` 启动。自行注册账号，并发布商品、帖子开始体验。

临时公网：本机准备完成后双击 `start-public-demo.bat`，从输出中取得新的 HTTPS 网址。服务会先备份，再复制数据库和图片到独立演示副本；公网与本机不自动同步。电脑须持续开机联网，停止演示后地址失效。详见 `PUBLIC_DEMO.md`。

## 数据与版本注意事项

交接包不含实际数据库、用户上传文件、真实 `.env`、私密配置、Git 历史、依赖和缓存。原电脑的体验账号、用户发布内容不会随源码包带走。若需交接数据，应另外通过私密方式传递数据库和图片备份。

前后端原本是两个独立 Git 仓库；源码包把两者配套放在一起，不等于已推送到 GitHub。若通过 Git 接手，应同时取得匹配的前后端分支。收到源码 ZIP 后可运行程序，但如需再次打包，须按 README 准备两个独立 Git 仓库并提交。

旧 PostgreSQL 库升级须先停止网页服务，再用 `npm run upgrade:postgres` 先备份、后新增缺失表。禁止删除 `.local/`、原数据库或上传目录。普通备份和恢复操作见根 README。
