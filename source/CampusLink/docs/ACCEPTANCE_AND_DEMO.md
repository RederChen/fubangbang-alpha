## 本机使用

双击根目录 `run-production.bat`，浏览器打开 `http://127.0.0.1:8080/`。不要用原来的免安装静态原型验收真实业务。

从上一版 PostgreSQL 项目升级时，先停止网页服务，执行：

```powershell
npm run upgrade:postgres
npm run build:release
npm run start:release
```

升级会先创建数据库和上传文件备份，再创建缺少的论坛表；不删除旧表、不覆盖原有数据。备份失败时不升级。该操作只支持本轮“新增表”，不代替将来的字段变更迁移。

从旧的四表备份恢复后，先使用恢复命令返回的标识执行 `npm run upgrade:postgres -- --restore <标识>`，再启动该恢复副本。恢复与升级都不会替换当前库。

新机器先按根 README 安装前后端依赖、准备 PostgreSQL。交接包没有真实账号和数据库，需要自行注册；论坛初始为空，发布后才出现内容。

## 论坛使用与内容管理

- 浏览：无需登录即可看列表、分类、标题或正文搜索、详情和评论。
- 发帖：点击“写帖子”，登录后填写标题、五选一分类、正文；封面可选，仅一张，最大 5 MB。
- 草稿：点击“存草稿”，同一账号在同一浏览器中可恢复；不会同步到服务器或其他设备。
- 管理：在“我的 → 我的帖子”查看本人帖子，打开详情后编辑或删除。后端也会核验所有权。
- 评论：登录后可发评论，并编辑或删除本人评论；帖子作者不能代替其他评论者修改评论。
- 删除：必须在对话框确认。删除帖子同时删除其评论，提示中会明确说明。
- 内容：以纯文本显示，换行保留；不执行 HTML 或脚本。当前没有关注、点赞、管理员审核和嵌套回复。
- 上传：沿用已有图片接口。移除封面不会立即删除磁盘文件，孤立上传清理仍为后续事项。

## 建议演示流程（约 8 分钟）

1. 账号 A 注册登录，上传商品封面并发布，刷新确认商品仍存在。
2. 账号 B 搜索该商品、收藏、查看联系方式并申请预订。
3. A 接受请求并确认面交完成；B 刷新看到完成状态和商品售出。
4. A 发布一篇“图书馆自习经验”，选择“学习”分类并上传封面，刷新确认保存。
5. B 搜索该帖并发表评论；A 刷新看到评论。B 修改本人评论，A 无法编辑这条评论。
6. A 在“我的帖子”编辑正文，再展示删除确认并取消；保留这篇帖子供老师查看。
7. 展示测试结果和备份恢复记录，说明公网部署与扩展功能的当前边界。

推荐演示内容使用自拟的通用经验，避免填写真实联系方式或其他同学的私人信息。测试账号与测试内容只写入独立测试库，不会预填到日常使用的数据库。
