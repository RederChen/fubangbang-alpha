## 双账号演示步骤

1. 打开公网地址，等待服务唤醒；先确认图片、商品列表和论坛能正常读取。A、B 使用不同浏览器或独立会话注册登录。
2. A 发布 `DEMO_DATA.json` 中的演示商品，上传可分享的图片并刷新确认保存。B 搜索该商品、收藏和点赞。
3. A 检查顶部未读提示，进入消息中心查看点赞通知；B 申请预订并填写面交留言，A 从消息进入对应交易。
4. A 接受预订；B 查看状态通知。展示确认面交完成时，只对演示订单操作。拒绝、取消分支使用另一条演示订单。
5. A 发布示例经验帖；B 搜索、点赞并评论。A 检查评论和点赞通知，点击后进入帖子；B 可修改或删除自己的评论。
6. A 标记单条和全部已读，切换“未读”筛选并刷新，确认状态保留。B 取消再点赞，同一条内容不会再次刷通知。
7. 从“我的”进入本人发布、收藏、帖子、交易和消息中心；展示编辑权限与删除确认，不删除真实同学的内容。

消息不会因仅打开列表自动全部变已读。网页可见时每 30 秒检查未读数量，窗口恢复焦点会立即检查，也可手动刷新。内容删除后通知保留，但详情入口失效。

## 数据与环境

新安装环境和公网不是同一个数据库，不共用账号或内容。示例 JSON 不含真实个人资料或可用登录凭据；按模板自行注册 A/B，不要使用生产管理密钥作为网页密码。

已有本地 PostgreSQL 库升级：先停止网页，再 `npm run upgrade:postgres`，成功后 `npm run build:release`、`npm run start:release`。新机器安装步骤见 `HANDOFF_20261030.md`。数据库与上传文件应一起备份，云端图片单独管理。
