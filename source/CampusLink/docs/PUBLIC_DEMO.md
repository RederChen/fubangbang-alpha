# 临时公网演示

本功能通过 Cloudflare Quick Tunnel 将一个专用演示服务提供给外部访问，无需服务器账号或域名。它依赖这台电脑持续开机联网，关闭临时服务后地址失效；重新启动会生成新地址。不是长期托管。

## 启动与查看

双击根目录 `start-public-demo.bat`。首次运行从 Cloudflare 官方 GitHub Release 下载 Windows 连接程序，并核对发布方 SHA-256；仅存放在项目 `.cache/cloudflared/` 中，不安装系统服务、不修改路由器或防火墙。

程序会先备份当前 PostgreSQL 数据及上传文件，再恢复到全新的演示数据库和独立图片目录，通过生产模式运行已有编译页面，然后输出 `PUBLIC_DEMO_URL=https://...trycloudflare.com`。

当前运行地址保存在 `.local/public-demo/latest.json`，无需提交或分享这个文件，只分享其中的 HTTPS 网址即可。网站正常账号登录流程保持不变；启动时已有账号和内容会随快照复制，新修改只发生在演示副本中。

## 数据和停止

- 本机网站仍使用原始库；公网使用新建的 `campuslink_demo_<UUID>`，两者不自动同步。
- 演示开始后，本机新发布的内容不会自动出现在这次公网副本；公网新注册、发布和交易也不会改动本机原数据。
- 演示可包含当前商品、帖子及账号。分享地址前请使用演示资料，不填写真实私人联系方式。
- 公网服务每次使用独立随机登录签名密钥，不复用本机的登录令牌。
- 保持启动窗口运行。需要停止时按 Ctrl+C；停止仅关闭本轮演示服务与连接程序，副本和备份继续保留。
- `.local/public-demo/<UUID>/web.log` 与 `tunnel.log` 保存本轮日志；备份在 `.handoff-backups/`，不纳入 Git 或源码包。
- 没有额外访问门禁，拿到地址的人可以浏览公开商品和帖子。注册和写入仍受网站账号权限控制。

## 验证和后续

本轮已检查公网首页、商品列表、论坛、详情、健康接口、商品图片及两个体验账号的实际登录。浏览器检查结果见 `AUDIT_LOG.md` 第 18 节。

长期上线仍需要独立主机或托管平台、持久化数据库与图片、稳定地址、运行维护以及面向正式用户的访问与内容管理。临时演示副本可在后续安排中保留或重新迁移，不会自动替换本机数据。

官方说明：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
